# Ghar Sathi — Structured Website

## Folder structure
- Each HTML page is in the project root.
- `css/` contains the corresponding page-specific stylesheet.
- `js/` contains one separate JavaScript file for each page.
- `images/` is where your existing image assets should be copied.

## Run locally
Open the folder in VS Code and use Live Server, or run a local web server from this folder.

## Important
1. Copy your existing `images` folder into this project’s `images/` folder (logo, sofa, banners, service photos, etc.).
2. This conversion keeps the original page content, page-specific CSS, and page-specific JavaScript. It does not connect forms to a backend or turn the demo OTP into a real SMS OTP.
3. The login page is `index.html`; the customer home page remains `Home.html`.
